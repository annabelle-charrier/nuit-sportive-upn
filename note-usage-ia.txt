Projet : La Nuit Sportive de l’UPN


1. OUTILS UTILISÉS

J’ai utilisé ChatGPT pour m’aider à définir le concept
de l’événement, structurer les six pages du site,
préparer les textes et générer le code HTML, CSS
et le JavaScript du formulaire de démonstration.

La génération d’images de ChatGPT a servi à réaliser
des maquettes pour choisir l’ambiance visuelle du site.
Ces maquettes ne sont pas les photographies intégrées
dans la version finale.

J’ai utilisé Sublime Text pour enregistrer et modifier
les fichiers, puis mon navigateur pour tester le site.

J’ai utilisé GitHub pour déposer les fichiers
et GitHub Pages pour publier le site.


2. MES CHOIX ET MA PERSONNALISATION

J’ai choisi le nom de l’événement, son sous-titre,
sa date, ses horaires, son public et son tarif.

J’ai précisé le format de la course : 5 km chronométrés,
sur cinq boucles de 1 km, avec un classement.

J’ai également choisi les animations et le principe
d’une soirée accessible sans participer à la course.

J’ai fourni mon texte de présentation personnelle
et ma photographie, puis sélectionné les photographies
d’illustration sur Unsplash.

J’ai choisi une identité visuelle rouge, noire et blanche,
un fond nocturne et une mise en page différente
pour chaque page, tout en conservant une typographie
et un menu communs.


3. INTERVENTIONS DANS LES FICHIERS

J’ai intégré les codes dans six fichiers HTML distincts :
index.html, universite.html, evenement.html, programme.html,
infos.html et inscriptions.html.

La présentation visuelle est regroupée dans un fichier
CSS séparé : style.css.

J’ai ajouté les images dans le dossier images
et corrigé leurs noms et leurs chemins dans le code,
notamment pour tenir compte de leur extension .avif.

J’ai changé le lien du titre du site pour qu’il mène
à la page de présentation de l’événement.

Avec l’aide de ChatGPT, j’ai intégré :
- la justification des paragraphes ;
- mon portrait à droite de ma présentation ;
- le logo de l’université sur sa page dédiée ;
- le programme sous forme de chronologie ;
- les informations pratiques sous forme de fiches ;
- l’adaptation des pages aux petits écrans ;
- le recadrage des images selon la hauteur des textes ;
- des filtres CSS rouges pour les photos de course
  et de basket ;
- une rubrique de crédits photographiques avec des liens
  vers les sources et la licence.

J’ai remplacé les premières illustrations par quatre
photographies proposées sous licence Unsplash.

Les corrections techniques proposées par l’IA ont été
copiées, intégrées et enregistrées manuellement
dans Sublime Text. J’ai ensuite vérifié le résultat
dans mon navigateur et mis à jour les fichiers sur GitHub.

5. CARACTÈRE FICTIF DU PROJET

La Nuit Sportive de l’UPN est un événement fictif
imaginé dans le cadre du cours de communication digitale.
Il n’est pas officiellement organisé par l’université.

La date, le programme, les animations, le parcours
et le prêt de matériel font partie du scénario imaginé.

Les photographies illustrent l’ambiance souhaitée
et ne représentent pas un événement réellement organisé
sur le campus.

Le formulaire est une démonstration :
aucune inscription réelle, aucun paiement
et aucun enregistrement de données par le site
ne sont effectués.
